**[papertool.in](https://papertool.in)** &nbsp;![Live](https://img.shields.io/badge/live-1D9E75?style=flat)

A SaaS PDF template builder — design templates visually, fill them with JSON via API, get PDFs back.

**Features**
- 🖱️ Canvas drag-and-drop editor with pixel-accurate PDF output
- 🔑 Developer REST API — Bearer auth, POST JSON → receive PDF
- 📊 Plan limits, usage tracking, full subscription billing
- 🧩 Tables, barcodes, QR codes, SVG import, gradients, graphs
- 🔧 Dynamic fields, multi-page support, font library
